# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome!

Thank you for your interest in contributing to this project. We appreciate all forms of involvement from the open-source community.

## How to Contribute

1. **Fork the Repository**: Create your personal fork of the project on GitHub.
2. **Clone the Fork**: Clone your fork to your local environment.
   ```bash
   git clone https://github.com/<your-username>/github-final-project.git
   ```
3. **Create a Branch**: Create a feature branch for your changes:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Make Changes**: Test your modifications thoroughly.
5. **Commit & Push**:
   ```bash
   git commit -m "Add detailed description of changes"
   git push origin feature/my-new-feature
   ```
6. **Open a Pull Request**: Submit your pull request to the `main` branch with a clear summary of your work.

## Reporting Bugs & Suggesting Ideas
If you find a bug or have an enhancement idea, please open an Issue with detailed reproduction steps or feature descriptions.
